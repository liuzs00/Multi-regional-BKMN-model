# References

Consolidated list for the whole dissertation, alphabetical by author. Data
sources carry the vintage and extraction actually used, since several are
published as revisable panels and the results depend on which release was drawn.

---

OECD (2025b). *OECD Greenhouse Gas Footprints Database*, 2025 edition. Paris:
